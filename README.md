# 文本批量替换 (Txt Replacer) v2.0

一个**纯本地**的 Android 文本批量替换工具：粘贴/打开文本，用**多个可自定义的替换库**批量替换，支持常见编码（UTF-8 / GBK / GB2312 / Big5 等）。

**🔒 纯本地：所有数据只保存在手机本地，不联网、不上传、无广告、无追踪。**

## ✨ 功能

- 📚 **多替换库（多配置）**：可新建任意多个命名库（如「库1」「库2」「库3」…），每个库独立命名、独立保存自己的一套替换规则，适配不同场景，互不干扰
- 🔧 **批量替换**：每个库可添加任意多条规则（查找词 → 替换词），执行时全部替换，**非单次替换**
- 🎯 **多字优先**：自动按查找词长度从长到短执行，长的优先替换，避免短词截胡（例：`xiejing→泄精` 优先于 `xie→邪`）
- 📝 **粘贴 / 本地 / 清空**：输入区三键，一键粘贴剪贴板、从本地读取 txt、一键清空
- 🔤 **编码设置**：UTF-8 / GBK / GB2312 / Big5 / UTF-16LE / ASCII，读取和保存均可按所选编码
- 📖 **长文本查看**：输入框、结果框支持长按选中/全选/删除；多行长文本可配合光标拖动查看
- 🧹 **清空按钮**：一键清空输入 / 清空结果
- 💾 **保存自由选路径**：保存时弹出系统文件选择器，自己选存放位置（默认 Download 等可写目录），**无需 root、无需存储权限**
- 📋 **一键复制**：替换结果可一键复制到剪贴板

## 📲 安装说明

> ✅ **本 APK 已带签名（debug 签名，v2 签名方案），可直接安装**，一般无需额外处理。

### 安装步骤
1. 下载 APK 传到手机
2. 点击安装，若提示「未知来源 / 允许安装未知应用」→ 允许
3. 若仍被拦截，多为国内 ROM 或系统安全策略，见下方「如遇拦截」

### 如遇拦截（极少数）
部分手机默认不允许安装非应用商店的应用，可尝试：
- 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」中给文件管理器/浏览器开启「允许安装未知应用」
- 或取消勾选「Play Protect 扫描应用」，再重新安装

### 关于签名
- 构建默认使用 **debug 签名**（v2 签名方案），可正常安装运行；安装包未更换正式发布签名，无法通过 Play 商店分发
- 如需正式发布签名（上架商店），开发者需在 `build.gradle.kts` 配置自己的 `signingConfigs` 并重新构建

## 📦 下载

- **正式发布版**：右侧 **Releases** → `v2.0.0` → 下载 APK
- **最新构建**：Actions 页面 → 底部 **Artifacts** → `txt-replacer-apk`

## 🛠️ 构建（开发者）

```bash
./gradlew assembleDebug    # 调试版
./gradlew assembleRelease  # 发布版（需配置签名）
```
APK 输出在 `app/build/outputs/apk/<variant>/`。

云端自动构建：推送到 `main` 分支即触发 GitHub Actions 编译打包。

## 🧱 技术栈

- Kotlin + Android View (XML)
- Gradle + GitHub Actions 云端构建（CI）
- ICU4J charset（`com.ibm.icu:icu4j-charset`）支持 GBK/GB2312/Big5 等安卓原生不支持的编码

- **不联网、不上传、不收集任何数据、无广告、无第三方 SDK**
- 无需任何权限即可运行
